Статус: **проектирование завершено, реализация не начата** (см. [BACKLOG](docs/BACKLOG.md)).

## Кратко о решениях

- **PWA** (Android, iOS, ПК — один код). Frontend: React + TypeScript + Vite + Tailwind + TanStack Query.
- **Backend:** Python + FastAPI, SQLAlchemy 2, Alembic. **БД:** PostgreSQL.
- **Хостинг:** российский VPS, Docker Compose, Caddy (HTTPS), ежедневные бэкапы.
- **Авторизация:** email + пароль, долгая сессия (180 дней), приглашение в дом по ссылке, сброс пароля по ссылке от члена семьи (без почтового сервера).
- **Все члены дома равны.** Несколько домов на пользователя заложены в схему с первого дня.
- **Этапы:** MVP (учёт) → 2 (ускорение ввода: штрихкоды, чеки) → 3 (рецепты, список покупок) → 4 (YouTube, «хватит на…»).

## Первичная настройка

Нужны git и [uv](https://docs.astral.sh/uv/). Один раз на машину и на каждый клон:

```bash
uv tool install pre-commit && uv tool update-shell   # затем перезапустить терминал
pre-commit install                                  # проверки при каждом git commit
pre-commit run --all-files                          # проверить весь репозиторий
```

Остальные команды (backend, frontend, справочник) — в разделе «Команды» [CLAUDE.md](CLAUDE.md).

## Как вести разработку

Процесс описан в [docs/agent/WORKFLOW.md](docs/agent/WORKFLOW.md). Коротко:

```
выбрать задачу из BACKLOG → /task-start T-xxx  (агент: предложение + вопросы, СТОП)
→ ответы оператора        → /task-implement T-xxx (сначала падающие тесты, потом код)
→ /task-finish T-xxx      (DoD, обновление документации, уроки, коммит)
```

Замечания оператора, которые стоит запомнить, фиксируются командой `/lesson` в [docs/agent/LESSONS.md](docs/agent/LESSONS.md) — агент читает этот файл в начале каждой задачи.
