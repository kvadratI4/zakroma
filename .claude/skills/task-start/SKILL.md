# /task-start $ARGUMENTS

Цель шага — **понять задачу и договориться**, а не реализовать. Код и тесты на этом шаге не пишутся.

0. Проверь, не пора ли сводка статуса (WORKFLOW, «Сводки статуса»): число `Done` в BACKLOG кратно 5 или закрыт этап, а в `docs/status/` сводки за этот повод ещё нет → сначала `/status-report`, потом продолжай.
1. Найди `$ARGUMENTS` в `docs/BACKLOG.md`.
   - Статус должен быть `Ready`. Если нет — сообщи оператору и остановись.
   - Проверь, что все задачи из «Зависит от» в статусе `Done`. Если нет — сообщи и остановись.
   - Проверь WIP-лимит: других задач в `Proposal`/`In progress` быть не должно.
2. Открой `tasks/$ARGUMENTS.md`; если файла нет — создай из `templates/TASK.md`, перенеси строку и критерии приёмки из BACKLOG.
3. Прочитай только нужное: требования по ID из задачи (`docs/02-requirements.md`), соответствующие разделы `docs/05-domain-rules.md`, `docs/06-api.md`, `docs/04-data-model.md`, связанные ADR, и существующий код в затрагиваемых местах. Уроки из `docs/agent/LESSONS.md` уже в контексте — примени те, что относятся к задаче, и упомяни их ID в предложении.
4. Заполни раздел **«3. Предложение»**:
   - 3.1 понимание задачи своими словами (2–5 предложений) — оператор должен узнать в нём свой замысел;
   - 3.2 подход;
   - 3.3 затрагиваемые файлы (создать / изменить);
   - 3.4 **план тестов** — таблица: каждый критерий приёмки → один или несколько тест-кейсов (уровень: unit / integration / component / e2e);
   - 3.5 изменения контрактов (API, схема, доменные правила, зависимости) — или «нет»;
   - 3.6 риски, альтернативы, что сознательно НЕ делаем (вне рамок).
5. Заполни раздел **«4. Вопросы»**: только то, что меняет реализацию. Каждый вопрос — с вариантами и рекомендацией. Если вопросов нет — так и напиши.
6. Если задача размера L или предложение явно больше одной-трёх сессий — предложи разбиение на подзадачи вместо реализации целиком.
7. Поставь задаче статус `Proposal` в BACKLOG и в файле задачи. Добавь запись в «6. Журнал сессий».
8. В чат: 3–6 строк сути + пронумерованные вопросы. **Остановись.** Не продолжай, пока оператор не ответит и не скажет `/task-implement`.
