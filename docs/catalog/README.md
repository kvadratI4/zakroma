# Справочник продуктов

Стартовый глобальный справочник: **331 продукт в 26 категориях**, словарь из **32 бытовых мер** и меры для 307 позиций. Загружается в БД data-миграцией (задача T-020); правила использования — [ADR-0007](../adr/0007-household-products-from-catalog.md), бытовые меры и норма дома — [ADR-0013](../adr/0013-presence-tracking-household-measures.md).

> Значения — ориентиры для семьи из 3–4 человек, составлены «на глаз» по типичным упаковкам и срокам хранения. Их задача — дать разумные значения по умолчанию, а не точность. **Правьте смело**: любой продукт дома можно перенастроить в приложении, а эти файлы — для всех будущих домов.

## Файлы

| Файл | Содержимое |
|---|---|
| `categories.csv` | `slug, name_ru, icon, sort_order` |
| `products.csv` | позиции справочника (колонки ниже) |
| `measures.csv` | словарь бытовых мер: пачка, стакан, ложка, ломтик, банка… |
| `product_measures.csv` | меры каждой позиции: как покупают и как берут |
| `validate_catalog.py` | проверка после правки: `python3 docs/catalog/validate_catalog.py` (на Windows — `python`); с `--norms` — ещё и список норм дома по-русски |

Редактировать удобно в Excel/LibreOffice/Google Sheets: **кодировка UTF-8, разделитель — запятая**. После правки — запустить валидатор (он же запускается хуком pre-commit).

## Колонки `products.csv`

| Колонка | Пример | Смысл |
|---|---|---|
| `slug` | `buckwheat` | Неизменяемый идентификатор (латиница, `_`). Не переименовывать после запуска — на него ссылаются продукты домов |
| `name_ru` | Гречка | Название в интерфейсе |
| `aliases` | `гречневая крупа` | Синонимы для поиска, через `\|` |
| `category` | `grains` | Slug из `categories.csv` |
| `unit` | `g` | Базовая единица: `g`, `ml`, `pcs` |
| `tracking_mode` | `exact` | `exact` — при покупке вводят количество («2 пачки»); `level` — уровень, количество необязательно |
| `default_location_kind` | `pantry` | Куда кладётся по умолчанию: `fridge`, `freezer`, `pantry`, `cellar`, `balcony`, `other` |
| `critical_below` | `70` | Меньше — «почти нет» (хватит разве что на раз) |
| `low_below` | `300` | Меньше — «мало, пора докупить»; у продуктов с нормой дома — это и есть норма |
| `plenty_from` | `3000` | От этого — «много» |
| `excess_from` | `8000` | От этого — «избыток, пока не покупать» |
| `shelf_life_days` | `540` | Типичный срок хранения в обычном месте (дней) |
| `shelf_life_opened_days` | | Срок после вскрытия |
| `shelf_life_frozen_days` | | Срок в морозилке |
| `keep_in_stock` | `true` | Норма дома по умолчанию: «должно быть дома всегда, не меньше `low_below`» — продукт попадает в «Покупки» |

Пустая ячейка = значение не задано. Пороги, если заданы, должны идти по возрастанию: `critical_below ≤ low_below ≤ plenty_from ≤ excess_from` — валидатор это проверит. Правила расчёта — [05-domain-rules.md](../05-domain-rules.md).

## Бытовые меры

Дома считают не граммами, а пачками, стаканами, ложками ([05-domain-rules §1.1](../05-domain-rules.md#11-бытовые-меры)). Меры дают интерфейсу язык кухни: «2 пакета молока», кнопки «Стакан», «½ пачки», подсказку «≈ 5 пакетиков».

**`measures.csv`** — словарь:

| Колонка | Пример | Смысл |
|---|---|---|
| `slug` | `pack` | идентификатор |
| `one`, `few`, `many` | пачка, пачки, пачек | «1 пачка», «2 пачки», «5 пачек» |
| `gen` | пачки | «½ пачки», «меньше пачки» |
| `halves` | `true` | можно взять половину: «½ пачки» — да, «½ ложки» — нет |
| `sort_order` | `30` | порядок в списке выбора меры |

**`product_measures.csv`** — меры позиций:

| Колонка | Пример | Смысл |
|---|---|---|
| `product` | `milk` | slug позиции |
| `product_name` | Молоко | название позиции — **только для чтения человеком**, должно совпадать с `name_ru` в `products.csv` |
| `role` | `buy` | `buy` — как покупают (не больше одной): добавление и норма дома; `use` — как берут (не больше двух): быстрые кнопки |
| `measure` | `bag` | slug меры |
| `measure_name` | пакет | название меры — для чтения, совпадает с `one` в `measures.csv` |
| `amount` | `930` | сколько в мере, в базовой единице продукта (для `pcs` — целое) |
| `unit` | мл | единица `amount` — для чтения, совпадает с единицей продукта (`г`, `мл`, `шт`) |
| `sort_order` | `0` | порядок кнопок |

Колонки `product_name`, `measure_name`, `unit` нужны, чтобы файл читался в Excel без поиска по другим файлам; в базу они не загружаются, а валидатор проверяет, что они совпадают с `products.csv` и `measures.csv`. Строку «молоко — пакет 930 мл, стакан 200 мл» видно сразу:

```
milk,Молоко,buy,bag,пакет,930,мл,0
milk,Молоко,use,glass,стакан,200,мл,1
```

Пример: молоко — `buy` пакет 930 мл, `use` стакан 200 мл; творог — `buy` пачка 180 г (кнопка «½ пачки» из `halves`); чай в пакетиках — `buy` коробка 100 шт, `use` пакетик 1 шт; тушёнка (в штуках) — `buy` банка 1 шт, поэтому показывается «3 банки», а не «3 шт».

## Сознательные решения

- Овощи, фрукты, зелень, специи — режим `level` (без весов на кухне), пороги в граммах всё равно заданы — для случаев, когда пользователь укажет «≈ 2 кг». Меры овощей — «штука» (морковь ≈ 120 г) и для картофеля и лука — «сетка».
- Без мер — 24 позиции: фрукты в штуках (лимон, арбуз — и так понятно), мясо и рыба на вес (покупают «кусок» разного размера, удобнее килограммы) и торт.
- Специи без своей меры получают «пакетик 15 г».
- Консервы — в штуках (банках) с мерой «банка» = 1.
- Продукты без порогов (арбуз, торт, алкоголь) не дают предупреждений «мало/избыток» — это разовые покупки.
- Для замороженных продуктов `shelf_life_days` = срок **после разморозки** в холодильнике; основной срок — `shelf_life_frozen_days`.
- Категория «Готовая еда» — для домашних остатков (суп, котлеты): у них короткий срок, и именно они чаще всего портятся.
- Категория `other` пустая — для продуктов, созданных пользователями.

## Что стоит проверить оператору в первую очередь

1. `keep_in_stock = true` — **норма дома** (сейчас у 20 позиций: картофель, лук, чеснок, морковь, молоко, масло сливочное, яйца, гречка, рис, макароны, мука, сода, хлеб, соль, перец чёрный, лавровый лист, масло подсолнечное, сахар, мёд, чай). Это то, что приложение покажет в «Покупках», когда закончится или станет мало. Посмотреть нормы по-русски: `python docs/catalog/validate_catalog.py --norms` — «Молоко — не меньше 500 мл, почти нет: < 200 мл, покупают: пакет 930 мл». Норма = `low_below`, «почти нет» = `critical_below`.
2. Меры повседневных продуктов (`product_measures.csv`): размер пакета молока, буханки, пачки творога — как покупает ваша семья.
3. Пороги для основных круп, сахара, муки — под реальные объёмы вашей семьи.
4. Недостающие продукты, которые вы покупаете регулярно.
