# 10. Визуальный стиль «Фарфор»

Утверждён оператором 2026-10-24 (T-004) из трёх вариантов концепта: [docs/design/concept.html](design/concept.html) · опубликованная страница — https://claude.ai/artifact/Lv2yPFkG9mWWrsd9zCdxTo. Источник истины для цветов и размеров в коде — `frontend/src/shared/theme/tokens.ts`; этот документ и токены меняются вместе.

## 1. Замысел и приоритеты

«Закрома» — **дом, в котором всё на своих местах**: тёплый, спокойный, современный интерфейс с ощущением дорогой вещи. Места хранения (холодильник, морозилка, шкаф, балкон) узнаются с первого взгляда, а роспись — как вышитый край полотенца: заметна, но не спорит с содержимым.

Приоритеты (оператор): **функциональность > дизайн**; главное — домашний уют, гармония, эстетика; старорусский шрифт и роспись — **точечное дополнение**: «спокойно, но с выделением основных моментов».

## 2. Темы

Тема — по системной настройке (NFR-UX-05); ручной выбор «Как на устройстве / Светлая / Тёмная» — T-009.

| Роль | Светлая — **гжель** | Тёмная — **хохлома** |
|---|---|---|
| `ground` (фон экрана) | `#ffffff` фарфор | `#110d0a` чёрный лак |
| `surface` (панели мест) | `#f0f3f9` | `#1b1510` |
| `raised` (строки, карточки) | `#ffffff` | `#241b15` |
| `border` | `#dde3ee` | `#34291f` |
| `text` | `#111a30` | `#f4ecdf` |
| `muted` (вторичный текст) | `#4b556e` | `#b9aa95` |
| `accent` (главное действие, активное) | `#1d4ea6` кобальт | `#d9a441` золото |
| `on-accent` | `#ffffff` | `#1a120b` |
| `ornament` / `ornament-fill` | `#1d4ea6` / `#c3d2ee` | `#d9a441` / `#c8432b` киноварь |
| `negative` (просрочено) | `#b3261e` | `#ff8a78` |
| `warning` (скоро испортится) | `#8f4a07` | `#f2b46a` |

Все пары «текст/фон» — не ниже 4,5:1, контролы и крупный текст — не ниже 3:1 (WCAG AA); проверяется тестом по `tokens.ts`.

## 3. Шрифты

| Роль | Шрифт | Где |
|---|---|---|
| Заголовки (устав) | **Triodion** (А. Андреев, OFL) | слово-логотип «Закрома», приветствие-заголовок экрана, названия мест хранения, крупные заголовки первого экрана и пустых состояний |
| Текст | **Golos Text** 400/500/600 (А. Королькова, В. Кузьмин, OFL) | всё остальное: строки продуктов, количества (табличные цифры), кнопки, подписи |

- Шрифты лежат в приложении (Fontsource, только кириллица и латиница), без запросов к внешним сервисам.
- Triodion — только от 20px и только короткие строки; в нём нет «№» (не нужен в заголовках).
- Размеры: приветствие 36px на телефоне / 48px на компьютере; место хранения 24px; текст 16px; вторичный 14px; подписи меню 12px — минимум.

## 4. Композиция

- Экран открывается **приветствием-заголовком** с главным фактом дня («Добрый вечер» и строкой ниже: «Кефир — до завтра, сметану пора выбросить»), а не баннером.
- Места хранения — панели `surface` с радиусом 20px, строки продуктов внутри — `raised` с радиусом 12px; без теней, без градиентов, без рамок вокруг каждого блока.
- В строке: название (500), под ним срок или уровень; количество справа табличными цифрами.
- Кнопки и переключатели — «таблетки» (полное скругление); зоны нажатия ≥ 44px.
- На компьютере (≥ 1024px): боковая панель 248px, сетка 12 колонок; список и карточка продукта рядом.

## 5. Роспись

- Только собственные векторные мотивы по мотивам гжели/хохломы: **купавка** (холодильник), **цветок-снежинка** (морозилка), **колос** (шкаф), **рябина** (балкон), прочие места — купавка. Не копировать изделия; слова «Гжель»/«Хохлома» не использовать в названии и логотипе.
- Где роспись есть: эмблема места (34px), тонкая **кайма** 12px под шапкой, крупная композиция на первом экране и в пустых состояниях.
- Где её нет: строки продуктов, цифры, кнопки, уровни, формы.
- Цвета росписи — только токены `ornament` / `ornament-fill` текущей темы.

## 6. Навигация (предварительная)

Пять мест, «Добавить» ровно по центру: **Запасы · Сроки · ＋ Добавить · Покупки · Семья**. На компьютере — боковая панель с кнопкой «Добавить» над пунктами.

| Пункт | Что внутри |
|---|---|
| Запасы | всё, что есть дома, по местам/категориям; настройка мест |
| Сроки | просрочено, скоро испортится — «что съесть первым»; «Съели» / «Выбросить» |
| ＋ Добавить | добавление продукта |
| Покупки | закончилось, критически мало, мало; «Пока не покупать» — избыток; в S3 здесь же список покупок |
| Семья | участники, приглашение, профиль, настройки дома, переключение дома |

**Навигация предварительная** (оператор, 2026-10-23: «пока ок, но, возможно, потом поменяем»). В коде панель строится из одного списка пунктов (`NAV_ITEMS`), поэтому смена состава — правка списка; пересмотр — после пилота с семьёй (T-044) или по решению оператора.
