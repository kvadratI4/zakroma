# 0002. Хостинг: российский VPS + Docker Compose

- Статус: Accepted
- Дата: 2026-10-23

## Контекст

Изначально рассматривался GitHub Pages. Он раздаёт только статику, поэтому для базы, авторизации и серверных функций понадобился бы BaaS (Supabase/Firebase). Пользователи находятся в России: зарубежные BaaS бывают недоступны, бесплатные проекты «засыпают». Семья должна открывать приложение по обычной ссылке без VPN.

## Рассмотренные варианты

| Вариант | Итог |
|---|---|
| GitHub Pages + Supabase | Отклонён: риск доступности из РФ, засыпание бесплатного проекта, ограниченность серверной логики |
| Домашний сервер + Tailscale | Отклонён: каждому члену семьи нужен VPN-клиент; зависимость от домашнего интернета/электричества |
| Бесплатные PaaS | Отклонены: засыпание, доступность из РФ |
| **Российский VPS + Docker Compose** | **Принят** |

## Решение

VPS в РФ (300–600 ₽/мес), Docker Compose: Caddy (HTTPS + статика), FastAPI, PostgreSQL, контейнер бэкапа. Один домен для SPA и API.

## Последствия

- Плюс: доступно всем без VPN, полный контроль, персональные данные хранятся в РФ.
- Плюс: свой backend снимает ограничения на серверную логику (S2–S4).
- Минус: администрирование (обновления, бэкапы) — снижается автоматизацией (unattended-upgrades, бэкап-контейнер, CI-деплой).
- Минус: небольшая регулярная плата.
