# 0007. Продукты дома создаются из глобального справочника при первом использовании

- Статус: Accepted
- Дата: 2026-10-23

## Контекст

Нужен стартовый справочник (~300 позиций), который ускоряет ввод. При этом каждая семья хочет править пороги и сроки «под себя» и добавлять свои продукты.

## Решение

- `catalog_products` — глобальный справочник только для чтения, загружается миграцией из `docs/catalog/products.csv`.
- `products` — продукты дома. Создаются **копированием** позиции справочника при первом выборе (сохраняется `catalog_slug`) или вручную.
- Поиск показывает продукты дома и ещё не использованные позиции справочника.

## Альтернативы

- Копировать весь справочник в дом при создании — 300 ненужных строк, засорение списков.
- Хранить только переопределения поверх справочника — сложнее запросы и логика «что из чего взято».

## Последствия

- Обновление справочника (новые позиции) сразу доступно всем домам; изменения существующих позиций **не** затрагивают уже созданные продукты домов (осознанно).
- Уникальность: в доме не может быть двух продуктов с одним `catalog_slug`.
