# 0009. Процесс: предложение → вопросы → ответы → TDD-реализация

- Статус: Accepted
- Дата: 2026-10-23

## Контекст

Реализация ведётся ИИ-агентом под контролем оператора. Риски: агент делает «не то», тратит усилия на неверное понимание, повторяет одни и те же ошибки между сессиями.

## Решение

1. Задача берётся из [BACKLOG](../BACKLOG.md), для неё создаётся файл `tasks/T-xxx.md` по шаблону.
2. Агент пишет **предложение** (подход, затрагиваемые файлы, план тестов, риски) и **вопросы** — и останавливается.
3. Оператор отвечает; ответы записываются в файл задачи.
4. Реализация по TDD: падающие тесты → код → рефакторинг.
5. Завершение по Definition of Done: тесты, линтеры, документация, BACKLOG, уроки.
6. Замечания оператора, применимые в будущем, записываются в `docs/agent/LESSONS.md`; агент читает его в начале каждой задачи.

Подробности — [docs/agent/WORKFLOW.md](../agent/WORKFLOW.md).

## Последствия

- Медленнее на старте задачи, быстрее и надёжнее в целом.
- Файлы задач — долговременная память проекта: почему сделано так.
