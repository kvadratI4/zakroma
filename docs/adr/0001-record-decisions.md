# 0001. Фиксировать архитектурные решения в ADR

- Статус: Accepted
- Дата: 2026-10-23

## Контекст

Разработка ведётся оператором совместно с ИИ-агентом (Claude Code) короткими сессиями. Агент не помнит прошлые сессии; оператор может забыть, почему что-то сделано именно так.

## Решение

Решения фиксируются в `docs/adr/` по шаблону `templates/ADR.md`. Агент читает индекс ADR перед предложением реализации и не предлагает решений, противоречащих принятым ADR, без явного упоминания конфликта.

## Последствия

- Плюс: контекст «почему» не теряется между сессиями.
- Минус: небольшие накладные расходы на запись. Мелкие решения записываются не в ADR, а в журнал задачи.
