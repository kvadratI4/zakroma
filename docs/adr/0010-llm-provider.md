# 0010. Выбор LLM-провайдера для S2–S4

- Статус: **Proposed** — решить перед стартом S2 (задача T-120)
- Дата: 2026-10-23

## Контекст

LLM нужна для: сопоставления строк чека с продуктами (S2), распознавания фото чека (S2), идей блюд (S3), структурирования рецептов из YouTube (S4). Сервер находится в РФ. Крупные зарубежные провайдеры (OpenAI, Anthropic, Google) ограничивают доступ из России, поэтому прямые вызовы с российского VPS могут не работать. Бюджет — несколько долларов в месяц, если приложение приживётся.

## Варианты для оценки

| Вариант | Что проверить |
|---|---|
| YandexGPT (Yandex Cloud) | Качество структурированного вывода (JSON), мультимодальность (фото чека), цена |
| GigaChat (Сбер) | То же |
| Зарубежные модели через доступный из РФ шлюз/агрегатор | Законность и надёжность, цена, задержки |
| Локальная модель на VPS | Нереалистично на 2 ГБ RAM — только для сравнения |

## Требования к решению

- Работа через порт `LLMProvider` (структурированный вывод по JSON-схеме, опционально — изображение на входе).
- Месячный лимит расходов и флаг отключения (NFR-COST-02).
- Набор из ~30 реальных строк чеков как эталон для сравнения качества.
