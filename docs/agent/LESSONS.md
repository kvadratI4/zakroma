# Уроки проекта

Загружается в каждую сессию агента (через `CLAUDE.md`). Формат записи — [templates/LESSON.md](../../templates/LESSON.md). Добавлять — командой `/lesson` с подтверждением оператора. Держать коротким (≤ ~150 строк); устаревшее — в `LESSONS_ARCHIVE.md`.

Уроки `L-001…L-013` записаны заранее по итогам проектирования (2026-10-23); часть проверена на реальном Postgres при подготовке документации.

## Процесс

- **L-001** Не пиши код и тесты до ответа оператора на предложение. — Почему: оператор хочет согласовать подход до затрат. (проектирование)
- **L-002** Задавай вопросы пачкой, с вариантами и рекомендацией; не спрашивай то, что уже есть в docs. — Почему: экономит время оператора. (проектирование)
- **L-003** Не добавляй зависимости и внешние сервисы без явного «да». — Почему: проект живёт на маленьком VPS, каждая зависимость — поддержка. (проектирование)

## Данные и БД

- **L-004** Количества — только `Decimal` в базовой единице продукта (`g`/`ml`/`pcs`). — Почему: `float` даёт 0.30000000000000004 г и ломает сравнения с порогами. (проектирование)
- **L-005** Для нечёткого поиска используй `zk_search_fold()` + `word_similarity`/`<%`, а не `similarity`/`%`. — Почему: проверено — `%` не находит «макорон» в «макароны паста|…», а без свёртки гласных «малако» не находит «молоко». (проверено 2026-10-23)
- **L-006** Чисти тестовую БД через `TRUNCATE … CASCADE` или откат транзакции, не через `DELETE`. — Почему: триггеры `stock_events` запрещают DELETE (журнал только на запись). (проверено 2026-10-23)
- **L-007** При загрузке CSV справочника пустые `aliases` превращай в `''`, остальные пустые ячейки — в `NULL`. — Почему: `aliases NOT NULL`; `\copy` даёт NULL — загрузка падала. (проверено 2026-10-23)
- **L-008** Любой новый household-scoped объект — с `household_id` и составными FK `(household_id, x_id)`. — Почему: база сама не даст смешать данные домов. (проектирование)

## Backend

- **L-009** «Сегодня» — в часовом поясе дома и только через `Clock`/параметр, не `date.today()`. — Почему: сервер может быть в UTC, сроки «сегодня последний день» поедут на 3 часа. (проектирование)

## Frontend / UX

- **L-010** Не прячь действия в жесты (свайп, долгое нажатие) без видимой кнопки. — Почему: пользуются пожилые члены семьи. (проектирование)
- **L-011** В интерфейсе — бытовые слова («Закончилось», «Выбросить»), не термины из кода («партия», «списание»). (проектирование)

## Документация

- **L-013** В Mermaid `sequenceDiagram` не ставь `;` в тексте сообщений (используй запятую). — Почему: `;` — разделитель операторов, диаграмма не рендерится. (проверено 2026-10-23)

## Окружение и интеграции

- **L-012** Не закладывай прямые вызовы OpenAI/Anthropic/Google API с сервера: VPS в РФ, доступ может быть заблокирован. Только через порт и ADR-0010. (проектирование)
