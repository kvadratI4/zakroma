# Глоссарий (UI ↔ документация ↔ код)

| В интерфейсе | В документации | В коде / БД |
|---|---|---|
| Дом | дом (одна квартира, дача) | `household` |
| Кто живёт в доме, участник | член дома | `member`, `household_members` |
| Настройки (раздел меню, бывш. «Семья») | настройки дома и пользователя | `settings` |
| Место (Холодильник…) | место хранения | `storage_location`, `location`, `kind` |
| Проверить холодильник, Остальное на месте | проверка места | `storage_locations.checked_at`, `POST …/locations/{id}/checked` |
| Сверим запасы?, Не сейчас, Предлагать сверить запасы | предложение ревизии | `revision`, `users.revision_reminder_days`, `revision_snoozed_until`, `stock_events.source = check` |
| — | справочник, позиция справочника | `catalog`, `catalog_product`, `slug` |
| Продукт | продукт дома | `product` |
| (строка в месте) | партия | `inventory_item`, `item` |
| Есть / нет | наличие (главное, что учитываем) | сводный уровень, ADR-0013 |
| Сколько | количество (базовая единица) | `quantity`, `unit` (`g`/`ml`/`pcs`) |
| Пакет, пачка, стакан, ложка, ломтик… | бытовая мера | `measure`, `measures`, `product_measures` |
| Как покупаем («пакет 930 мл») | мера покупки | `role = buy` |
| Как берём («стакан 200 мл»), кнопки «−1 стакан», «−½ пачки» | мера использования | `role = use`, `halves` |
| ≈ 5 пакетиков, меньше стакана | подсказка в мерах | `level_hint` |
| ≈ | приблизительное количество | `quantity_is_approx` |
| Нет / Почти нет / Мало / Нормально / Много / Избыток | уровень | `level` 0–5: `out, critical, low, normal, plenty, excess` |
| — | пороги | `critical_below, low_below, plenty_from, excess_from` |
| Всегда держать дома: не меньше N | норма дома | `keep_in_stock` + `low_below` |
| (уровень-кнопка в строке) | отметка наличия | `mark`, event `level_set` |
| Закончилось | отметка «нет» | `mark(level=out)`, event `consumed` |
| Годен до | срок годности | `expires_on` |
| ≈ до… (обычно неделя) | расчётный срок | `expiry_source = estimated` |
| — | эффективный срок | `effective_expiry` |
| Вскрыто | дата вскрытия | `opened_on` |
| Съели, −1 стакан, −½ пачки | использовано (необязательно) | `consume`, event `consumed` |
| Выбросить | выброшено (испортилось) | `discard`, event `discarded` |
| Исправить | исправление | event `adjusted` |
| Переместить | перемещение | `move`, event `moved` |
| История | журнал событий | `stock_events` |
| Запасы; по местам / по видам | сводка по продуктам | `stock`, `product_summary`, `group=location\|category` |
| Сроки / Покупки | экран предупреждений (два раздела меню, T-004) | `attention` |
| Скоро испортится / Просрочено | статус срока | `expiry_status`: `ok, expiring, expired, unknown` |
| Пока не покупать | избыток у продукта с нормой | `level = excess` |
| Добавить, «Добавить 3 продукта» | добавление списком (в том числе «после магазина») | `POST /items` с массивом |
| Как в прошлый раз | значения по умолчанию при добавлении | `default_location_id`, `last_added_quantity`, `defaults` |
| Обычно покупаете | частые продукты | `products/frequent` |
| Купили | добавление из «Покупок» | — |
| Пригласить | приглашение | `household_invite` |
| — | первый пришёл — первый ушёл по сроку | FEFO |
| — | оператор | человек, ведущий проект |
| — | агент | Claude Code |
