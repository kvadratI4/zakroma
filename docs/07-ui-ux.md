# 07. UI/UX

Цель — чтобы приложением пользовались **и подростки, и бабушка**. Каждый экран проверяется против [NFR-UX](02-requirements.md#удобство-ux).

## 1. Принципы

1. **Видимые действия вместо жестов.** Свайпы и долгие нажатия — только как дублирование видимых кнопок (взрослые их не находят).
2. **Одна главная кнопка на экране** — крупная, внизу, в зоне большого пальца.
3. **Значения по умолчанию заполнены**: место, единица, дата покупки = сегодня, количество = 1 упаковка.
4. **Слова, а не термины**: «Закончилось», «Выбросить», «Мало» — без «списание», «партия», «инвентаризация» в UI (это слова для кода и документации).
5. **Отмена вместо подтверждений.** После действия — тост «Списано: молоко 1 л · Отменить» (5 с). Модальные «Вы уверены?» — только для необратимого (покинуть дом).
6. **Цвет не единственный носитель смысла**: у уровней и статусов есть текст/иконка.
7. **Мобильная раскладка первична**; на ПК — две колонки (список + карточка).

## 2. Навигация

Нижняя панель (на ПК — боковая):

| Вкладка | Экран |
|---|---|
| Запасы | Список продуктов по местам/категориям |
| Внимание | Просрочено, скоро испортится, мало, избыток (бейдж с числом) |
| **＋** | Добавление (центральная крупная кнопка) |
| Дом | Места хранения, участники, приглашение, настройки, переключение дома |

Заголовок экрана: название дома (тап → переключение дома, если их несколько).

## 3. Экраны MVP

### 3.1. Вход / регистрация / приглашение

- Регистрация: email, пароль (с кнопкой «показать»), «Как вас зовут». Без подтверждения почты.
- Ссылка-приглашение открывает экран «Вас пригласили в дом „Квартира“» → «Зарегистрироваться» / «Уже есть аккаунт — войти».
- После первого входа — экран «Установите приложение» с инструкцией под платформу (Android: кнопка установки; iOS: «Поделиться → На экран Домой» с картинкой; ПК: иконка в адресной строке). Можно пропустить.

### 3.2. Запасы

```
┌───────────────────────────────┐
│ Квартира ▾            🔍       │
│ [По местам] [По категориям]    │
│ Фильтр: Все ▾                  │
├───────────────────────────────┤
│ ХОЛОДИЛЬНИК                    │
│ Молоко 3,2%    1,5 л   ≈ до 14.11 │
│   [−порция] [Закончилось]      │
│ Яйца           6 шт    до 28.11 │
│ Морковь        ● Нормально      │
│ МОРОЗИЛКА                      │
│ Пельмени       900 г   до 03.2027 │
│ БАЛКОН                         │
│ Сахар          ≈ 20 кг ▲ Избыток │
└───────────────────────────────┘
```

- Строка продукта: название, количество или уровень, ближайший срок (с «≈» для расчётного), значок статуса.
- Тап по строке → карточка продукта. Быстрые кнопки видны у раскрытой строки (тап по стрелке) — 2 самых частых действия.
- Группировка по местам: продукт, лежащий в нескольких местах, показывается в каждом месте своей частью; сводный уровень — в карточке и в группировке по категориям.

### 3.3. Добавление (＋)

```
Шаг 1: Что?                Шаг 2: Сколько?  
┌──────────────────────┐   ┌──────────────────────────┐
│ 🔍 мол|               │   │ Молоко 3,2%              │
│ Молоко 3,2%   (дома)  │   │ Куда: [Холодильник ▾]    │
│ Молоко топлёное       │   │ [1 уп. 930 мл] [−] [+]   │
│ Молочные сосиски      │   │ или: ___ [мл ▾]          │
│──── Часто покупаете ──│   │ Срок: [не указан ▾]      │
│ [Хлеб][Молоко][Яйца]  │   │  ≈ до 30.10 (типовой)    │
│ [Бананы][Сыр][Курица] │   │                          │
└──────────────────────┘   │      [ Добавить ]        │
                           └──────────────────────────┘
```

- **Путь в 3 тапа**: плитка «Молоко» → «Добавить» (всё по умолчанию) — 2 тапа; с поиском — 3.
- Для продуктов в режиме «уровень» шаг 2 — ряд кнопок уровня + необязательное «≈ сколько».
- Срок: по умолчанию «не указан» с подсказкой типового; тап → выбор даты (быстрые варианты: +3 дня, +7, +14, +30, календарь).
- **Режим «После магазина»** (переключатель на шаге 1): после «Добавить» возвращаемся к поиску, внизу растёт корзина «Добавлено: 7»; «Готово» сохраняет всё пакетом (FR-INV-04). Если сеть пропала — корзина не теряется (хранится локально до отправки).

### 3.4. Выбор уровня

Сегментированный ряд из 6 кнопок с цветом **и** подписью:

`[Нет] [Крит. мало] [Мало] [Норм.] [Много] [Избыток]`

Цвета: нет — серый, критически мало — красный, мало — оранжевый, нормально — зелёный, много — синий, избыток — фиолетовый. Порядок и цвета одинаковы везде.

### 3.5. Карточка продукта

- Сводка: сколько всего, уровень, ближайший срок, «держать дома» (переключатель).
- Партии по местам, у каждой: количество/уровень, срок, кнопки «−порция», «−½», «Закончилось», меню «⋯» (Вскрыто, Переместить, Выбросить, Исправить).
- История (последние 20 событий: «Мама · вчера · −200 г»).
- Настройки продукта (свернуто): единица, упаковка, порция, пороги (с пояснением «Мало — когда меньше…», «Избыток — когда больше…»), сроки хранения.

### 3.6. Внимание

Блоки (см. [правила](05-domain-rules.md#6-экран-внимание)): Просрочено → Скоро испортится → Закончилось → Критически мало → Мало → Избыток. В каждом элементе — главная кнопка: для сроков — «Съели» / «Выбросить», для «мало» — (S3: «В список покупок»).

### 3.7. Дом

Места хранения (перетаскивание для порядка, тип места), участники, «Пригласить» (ссылка + кнопка «Поделиться» через Web Share API), «Сбросить пароль участнику», настройки (порог «скоро испортится», часовой пояс), «Добавить дом», «Выйти».

## 4. Тексты

- Все строки — в `frontend/src/i18n/ru/*.json`, ключи по фичам (`inventory.actions.consumePortion`).
- Множественные формы — через i18next plurals (`1 день`, `2 дня`, `5 дней`).
- Тон — дружелюбный, без восклицательных знаков и канцелярита.

## 5. Пилот

Перед закрытием MVP — две недели использования семьёй (T-044): записывать, где люди «застряли», в `docs/agent/LESSONS.md` (раздел UX) и превращать в задачи.
