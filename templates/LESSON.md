# Формат урока

Одна строка в нужном разделе `docs/agent/LESSONS.md`:

```
- **L-NNN** <Правило в повелительном наклонении: «Делай X» / «Не делай Y»>. — Почему: <одно предложение>. (<T-xxx | дата | «проверено»>)
```

Хороший урок:

- конкретен и проверяем: «Количества — `Decimal`», а не «аккуратнее с числами»;
- содержит причину — без неё правило забывают или применяют не к месту;
- короткий: одна строка, максимум две;
- не дублирует CLAUDE.md, rules и документацию (если дублирует — значит, нужно поправить их, а не добавлять урок).

Примеры:

```
- **L-013** Перед изменением экрана на телефоне проверяй ширину 360 px. — Почему: у бабушки маленький Android, кнопки уезжали. (T-035)
- **L-014** Не вызывай `pnpm gen:api` до `uv run python scripts/export_openapi.py`. — Почему: генерирует клиент по старой схеме. (T-032)
```
