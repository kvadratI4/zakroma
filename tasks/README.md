# Файлы задач

Каждая задача из [BACKLOG](../docs/BACKLOG.md), взятая в работу, получает файл `T-xxx.md` по шаблону [templates/TASK.md](../templates/TASK.md). Агент создаёт его в `/task-start`, если файла ещё нет.

Файл — это **долговременная память по задаче**: понимание, план тестов, вопросы и ответы оператора, решения, журнал сессий (чтобы продолжить после перерыва), итог. После `Done` файлы не удаляются.

Пример готовой к старту задачи — [T-001.md](T-001.md).
